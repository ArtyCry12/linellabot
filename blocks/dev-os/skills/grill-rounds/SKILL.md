# Grill-rounds (адаптер)

**Upstream:** https://github.com/mattpocock/skills (MIT), skill `productivity/grilling`.  
**Adapter, не клон:** без Claude slash-commands `/grill-me`, без `setup-matt-pocock-skills`,
на русском, под AskQuestion и user-profile хаба. Карантин `skills/_quarantine/mattpocock-skills` не трогать.

## Когда

Большая задача / с нуля / план / «уточни» / «полный список вопросов» — **до старта работы**.
В середине протокола — НЕ гриллить. Исключения как в `rules/user-profile.mdc`:
commit, push, deploy, delete, secrets, mcp write, утверждение WBS.

## Дерево решений

Каждое решение — узел. У него ветви — решения, которые от него зависят.
Пока родитель не закрыт, потомок в **тумане** — его нельзя спрашивать.

## Раунды (фронтир)

**Фронтир раунда** = все вопросы, чьи предпосылки уже закрыты (можно задать сейчас, не угадывая ответы).

В одном сообщении — **весь фронтир**. Каждый вопрос:

```
❓ **Q1** — **<заголовок>**: <тело, может быть с вариантами выбора>

➡️ **Рекомендация:** <твой ответ и почему>
```

После ответов пользователя — пересчитать фронтир, задать следующий раунд.
Пока фронтир не пуст.

## Правила

1. **Факты — работа агента.** Файлы, репо, что уже есть — смотри сам (Read, Grep, GitNexus).
   Пользователя не спрашивать о том, что можно найти.
2. **Решения — работа пользователя.** Каждый вопрос с вариантами — ему.
3. **Предпочитай AskQuestion** (Cursor) для раунда с 2–4 вопросами — один блок, кнопки.
4. **Рекомендация обязательна** в каждом вопросе: твой выбор + одно предложение «почему».
5. **Не блокируй раунд на одном факте.** Если для под-вопроса нужен поиск — запусти его
   в фоне/параллельно, а остальной фронтир задай сейчас. Под-вопрос ждёт в следующем раунде.
6. **Стоп** — пользователь подтвердил общее понимание. Дальше код/сборка **без** «продолжать?».
7. **Язык** — простой русский. Без AI-жаргона.

## Не делать

- Не спрашивать по одному вопросу в сообщении (это не `brainstorming` Superpowers).
- Не вставлять `/grill-me` или Claude slash-commands.
- Не дублировать `prompt-engineering-coach` — у того свой route `prompt-coach` (уроки промта).
- Не восстанавливать карантинный `grill-me` как CORE.
- Не гриллить в середине длинного протокола.

## Связки

- `from-scratch` (новый проект) → сначала `wayfinder` (одна карта), затем grill-rounds, затем `task-decomposition` (WBS).
- Клиентский репо после согласования → `blocks/dev-os/skills/project-context/SKILL.md` (глоссарий, не хаб).
- `clarify-first` route → этот skill.
- После grill-rounds → `task-decomposition` для WBS.
