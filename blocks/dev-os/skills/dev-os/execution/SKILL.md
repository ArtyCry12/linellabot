# Dev OS — Executive Execution

Parent: [../SKILL.md](../SKILL.md) · Charter: [EXECUTIVE.md](../../../docs/dev-os/EXECUTIVE.md)

## Lifecycle (run to completion)

```
UNDERSTAND → RESEARCH → DESIGN → IMPLEMENT → VALIDATE → OPTIMIZE → AUDIT → FINALIZE → EVOLVE
```

Do not stop between phases. Do not ask for phase confirmation.

## Phase routing (Candidate A)

| Phase | Action |
|-------|--------|
| UNDERSTAND | Parse intent; check corpus + user-memory |
| RESEARCH | dev-os-research / Exa if external validation needed |
| DESIGN | decision skill; candidates only; DEC if structural |
| IMPLEMENT | Project Squad or domain skill |
| VALIDATE | squad-qa, tests, lint, dev-os-status |
| OPTIMIZE | token/routing per optimization domain |
| AUDIT | scout/review; evolution QA track |
| FINALIZE | docs, cleanup, consistency |
| EVOLVE | backlog + layers; ASM/DEC log |

## Interrupt gates

Security · irreversible architecture · critical missing data · data loss · legal/compliance · destructive ops.

## End condition checklist

- [ ] Implemented
- [ ] Validated
- [ ] Optimized (safe wins)
- [ ] Documented if durable
- [ ] No high-value gaps (or in backlog)

## Reporting (DEC-006)

Milestone summary only — not per-phase. One `Continue?` after major objective if needed.
