# Style lock (REQ-051)

Lock **once** per project before storyboard or gen. Change only on explicit user request.

## Ask if missing

1. **Visual style** — cinematic / UGC / kinetic type / faceless b-roll
2. **Platform** — TikTok, Reels, Shorts, LinkedIn (affects pacing)
3. **Palette** — 2–3 hex or "brand default"
4. **Talent** — on-camera / voiceover only / AI avatar (no on-camera)

## Expert recommendations (suggest, don't impose)

| Niche | Style | REF |
|-------|-------|-----|
| B2B SaaS | Face + screen PiP | REF-02, REF-16 |
| Education | Mistake→fix | REF-01 |
| E-commerce | Product hero | REF-18 |
| Personal brand | POV story | REF-06 |

## Record in

- `project-brief.md` § Style lock
- Top of `storyboard-json.prompt` as `palette` + `style` fields

| Style | Default track |
