# Copywriting Rationale — FlowMetrics 3-Page Demo

Applied **copywriting** skill principles (clarity, benefits, specificity, customer language).

## Homepage hero

| Element | Copy | Why (skill rule) |
|---------|------|------------------|
| Headline | "See what your team ships" | One idea, verb-driven, mirrors eng-lead language |
| Subhead | "4 hours → 15 minutes" | **Specificity over vagueness** — concrete time save |
| CTA primary | "Start 14-day trial" | Risk reversal before price page |
| CTA secondary | "See how it works" | Low-commitment for researchers |
| Microcopy | "No credit card · SOC 2" | Objection handling above fold |

**Avoided:** "Innovative," "streamline," "leverage," exclamation points.

## Features page

- Each card = **one benefit question** CTO asks Monday sync
- Metrics in cards (4×, &lt;2min) = **show over tell**
- Git integration CTA at bottom = single action per section

## Pricing page

- **Team tier highlighted** — price anchoring + social proof "Most popular"
- FAQ answers top 3 objections: security, speed, lock-in
- Enterprise "Custom" — avoids fake enterprise price

## Marketing psychology (product-marketing)

- Loss aversion: "Stop guessing"
- Social proof: "240+ teams" (demo placeholder — label as demo in production)
- Trial framing reduces friction before feature depth
