Автоматизация

Когда агент может сам, а когда спрашивает

Три режима. !auto не значит «делай что хочешь».

Можно сам (!auto)

Чтение файлов, grep, audit, lint fix, docs, мелкий рефактор, research через exa, локальные тесты без deploy.

Всегда спросить

git commit/push, deploy, удаление файлов, MCP write (email, slack), правка .env и секретов, force push.

Сначала план

Новая фича, архитектура, большой рефактор, security review, смена hooks/rules на always-on.
