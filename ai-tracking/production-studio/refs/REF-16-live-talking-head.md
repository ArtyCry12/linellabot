# REF-16 — Live shoot: talking head + B-roll · 45s

**Use:** Real people, marketing interview, founder clip.

## Pre-production
- **Talent:** 1 speaker + optional hands B-roll
- **Locations:** A-roll studio · B-roll product/office
- **Gear:** 2 cameras (A 35mm, B 85mm detail), lav mic

| Time | A-roll | B-roll |
|------|--------|--------|
| 0–5s | HOOK line to camera | — |
| 5–15s | Setup / stakes | Cutaway: problem in environment |
| 15–35s | 3 points with pauses | Product use, team, screen |
| 35–42s | Payoff one-liner | Hero product shot |
| 42–45s | CTA | Logo end card |

## Shot list
1. **Wide master** — full body, establish  
2. **Medium** — waist-up, primary delivery  
3. **CU** — eyes for emotional beat  
4. **B-roll** — hands, product, location texture  
5. **Insert** — phone screen / dashboard (optional)

## Director notes
- Pattern interrupt every 4–5s (angle or B-roll)
- No greeting — open mid-thought or with result
- CTA single action: follow / link / DM keyword
