# Урок: Notion mega-prompt — как формулировать системные задачи

**Дата:** 2026-07-10  
**Источник:** ваши 3 Notion-страницы + сессия P1→P2

---

## Что было хорошо

1. **Три отдельные страницы с ролями** — система / Production Studio / design stack. Агент смог собрать REQ-реестр без потери формулировок.
2. **Явные фазы P1→P2→P3** в тексте — позволили не смешать MCP-установку с тяжёлым Production Studio.
3. **«Полностью автоматизированно»** — понятный приоритет: меньше уточнений, больше действий.

## Что мешало LLM

1. **Один огромный промт без нумерации** — пришлось строить REQ-001…080 вручную. Риск пропустить пункт.
2. **Google Trio + OAuth** в одном блоке с лёгкими MCP — агент потратил время, пока не приняли GOOGLE-STACK-LITE.
3. **«Okara — жду вас»** без «залогинен»** — граница human-in-the-loop была неявной до второй попытки.
