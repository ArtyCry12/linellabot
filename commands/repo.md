# /repo — разбор репозитория без лишних вопросов

Кинь URL, путь или `@папку` — агент:

1. Разберёт репо (scout)
2. Предложит **A / B / C**
3. Сделает после твоего выбора

**Skill:** `skills/repo-intake/SKILL.md`

Примеры:

```
/repo https://github.com/user/some-skill
@C:\Users\Asus\Downloads\thing.zip
https://github.com/foo/bar — разбери
```

С `!auto` — выполнит лучший вариант (A), если очевидно.
