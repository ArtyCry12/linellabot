# На Maker’s Pet представили oomwoo — проект открытого робота-пылесоса, который можно собрать самому
...
На портале Maker’s Pet анонсировали проект oomwoo — робот-пылесос на открытой архитектуре, который можно собрать самому и модифицировать. Устройство должно получить доступное на рынке железо, прошивку с открытым кодом и модели корпуса для печати на 3D-принтере.
...
Главная идея oomwoo — сделать робот-пылесос без привязки к облаку и закрытой экосистемы производителя. В основе лежит Raspberry Pi, операционная система ROS 2, лидары для построения карты помещения и интеграция с Home Assistant. При этом базовые функции уборки будут работать локально без обязательного подключения к интернету. По задумке oomwoo должен стать не экспериментом для энтузиастов, а полноценным бытовым прибором с поддержкой от сообщества.
...
Ориентир по бюджету составляет примерно 500-600 долларов, что должно вписываться в цену среднебюджетных роботов-пылесосов. Этой суммы должно хватить на плату Raspberry Pi 5 с 4 ГБ памяти, готовые моторы, сенсоры и вакуумные модули с популярных китайских маркетплейсов. Корпус, шасси и док-станцию можно будет распечатать на 3D-принтере.
...
Сейчас проект находится на ранней стадии. У автора проекта пока есть только первая версия рабочей сборки, а для дальнейшего продвижения нужна помощь сообщества. Кроме того, рассматриваются варианты интеграции в будущем с LeRobot и OpenClaw, а также магазин приложений для кастомизации поведения пылесоса и сценариев использования.
...
У проекта есть GitHub-репозиторий с документацией и планами.
