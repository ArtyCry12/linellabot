# Порог готовности урока

## Автоматический урок (без «урок промта»)

Все условия:

1. **≥ 4** смысловых промта пользователя с прошлого урока (`minChars` ≥ 40, не noise)
2. **≥ 2** дней с `lastLessonAt`
3. Не больше **2** уроков в неделю (ручная проверка агентом)

**ИЛИ** milestone + ≥ 2 промта + 2 дня.

## Принудительный урок

Пользователь: «урок промта», `/prompt-lesson` — пиши при ≥ 1 смысловом промте.

## Не писать

- Мелкий вопрос-ответ без доставки
- Только системные промты в capture
- Урок в тот же день, что предыдущий (без явной просьбы)

## Конфиг

`lib/prompt-coach/CoachConfig.json` — пороги можно подкрутить.
