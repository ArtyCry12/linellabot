# Стиль brief-уроков

## Да

- Короткие абзацы, таблицы было/лучше
- Цитаты **ваших** фраз в кавычках
- «Ты написал X — модель подумала Y»
- Конкретные хуки: `!auto`, `P3 test`, `@seo-geo`
- Один блок «идеальный промт» в конце

## Нет (AI-slop)

- «В данном контексте…»
- «Ключевым аспектом является…»
- «Рад сообщить…»
- Длинные вступления и мотивационные абзацы
- 10+ исправлений за раз — максимум 3–5 сильных

## Тон

Как объясняет знакомый разработчик за кофе. Можно «ты». Можно лёгкий юмор, без панибратства.

## Длина

1–2 экрана. Читается за 3–5 минут.
